# Acceptance checklist

- Draw closed contours with mouse/touch and preserve pointer capture.
- Add multiple contours; undo latest contour; clear only selected glyph.
- Switch glyphs without losing drawings.
- Adjust simplification tolerance and curve tension independently.
- Inspect fitted cubic geometry and report contour/segment counts.
- Compile a TTF containing every non-empty glyph.
- Load the generated bytes using FontFace and render live specimen text with the loaded face.
- Export/import project JSON without losing raw source contours.
- Regression glyphs: A, O, S, R, a, g, i, m, 8. Validate counters, winding, joins and browser rendering.
- Typecheck/build cleanly; pointer interaction remains responsive.
